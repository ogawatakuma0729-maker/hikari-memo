# ひかりメモ（制作見本）

Python（Flask）で、フォームの内容を保存して一覧に出す見本です。
実在のサービスではありません。会員・決済はありません。

## 自分のパソコンで動かす

1. このフォルダで、次を実行する。
2. ブラウザで http://127.0.0.1:5000/ を開く。

```
python -m pip install -r requirements.txt
python app.py
```

「書く」で送ると、「一覧」に残ります。
